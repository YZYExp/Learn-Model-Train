# 03 训练方法如何选择

| 瓶颈 | 先试的系统方案 | 训练候选 | 主要代价 |
| --- | --- | --- | --- |
| 变化的外部知识 | 检索与工具 | 继续预训练或 SFT | 更新成本与知识时效 |
| 格式与流程 | 提示、约束输出、校验 | SFT | 示例偏差与遗忘 |
| 可比较的答案 | 明确评价标准 | DPO 等偏好优化 | 偏好噪声 |
| 可执行多步任务 | 工具与评估器 | 在线 RL | 采样成本与奖励漏洞 |
| 推理成本 | 量化、缓存、小模型 | 蒸馏 | 学生能力损失 |

预训练常以预测下一个 token 为目标。继续预训练改变领域数据分布；SFT 通过示范教模型完成任务。全参数微调更新全部可训练权重；LoRA 将更新约束为低秩矩阵，降低需要训练的参数和优化器状态，但基础权重、激活和临时缓冲仍占显存。QLoRA 使用量化的冻结基础模型与低秩适配器，实际效果和吞吐要在硬件与任务上测量。[LoRA](https://arxiv.org/abs/2106.09685)；[QLoRA](https://arxiv.org/abs/2305.14314)。

偏好优化可用同一问题下的优劣回答对训练；[DPO](https://arxiv.org/abs/2305.18290) 是其中一种。在线 RL 则由当前模型采样轨迹，再根据规则、执行结果或奖励模型反馈更新策略。验证器可能被钻空子：只检查最终文件可能奖励绕过任务的行为，需要独立隐藏测试和副作用检查。[GRPO 文档](https://huggingface.co/docs/trl/grpo_trainer)。

蒸馏可以用教师生成的样本训练学生，也可以使用教师概率分布；教师错误同样可能被传递。无论选哪种方法，都应固定独立测试集并比较质量、总成本和失败类型，不假设更复杂的方法一定更好。

缩放定律提供预算决策线索，但固定训练计算量下的经验结果不能直接变成所有场景的 token 与参数固定比例；推理调用量与部署成本也会改变选择。[Chinchilla 论文](https://arxiv.org/abs/2203.15556)；[推理成本与缩放](https://arxiv.org/abs/2401.00448)。
